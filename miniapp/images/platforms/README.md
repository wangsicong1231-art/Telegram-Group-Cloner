# 平台 Logo 图片

把 4 张平台 Logo 图片放到本目录（public/images/platforms/），文件名必须完全一致：

| 平台 | 文件名 |
|---|---|
| 南宫NG | `ng.png` |
| 开云体育 | `kaiyun.png` |
| 澳门新葡京 | `lisboa.png` |
| 澳门美高梅 | `mgm.png` |

放好后刷新网页即可显示。建议正方形图片（如 512×512），png 或 jpg 均可（jpg 也用 .png 后缀或改 config.js 里的扩展名）。
未放图时卡片会自动回退显示文字标识（NG / KY / 葡 / MGM）。
